# db-scrape — 爬蟲規則與過濾條件

---

## 目標

爬取 TII（台灣人壽保險局）的保單條款資料庫，**只保留個人人身保險**，過濾掉所有不適合進入資料庫的商品。

---

## 排除規則（符合任一條件就排除）

### 1. 團體保險

商品名稱含有以下任一關鍵字：
- `團體`
- `團險`
- `集體`
- `團保`
- `Group`（大小寫均算）

商品類別為：
- `健康保險（團體）`
- `傷害保險（團體）`
- `人壽保險（團體）`

### 2. 延續條款 / 停售後續

商品名稱含有以下任一關鍵字：
- `延續條款`
- `停售後續`
- `附約延續`

> ⚠️ 注意：「延續」單獨出現不一定是延續條款，需要配合「條款」或「停售後續」一起出現才排除。

### 3. 純附約（非主約人身保險）

商品名稱以 `附約` 結尾，且不含以下人身保險核心關鍵字：
- 醫療、意外、癌症、失能、長照、重大傷病、特定傷病、壽險、定期、終身

## UUID 抽取規則

每個商品的 PDF URL 格式為：
```
https://insprod.tii.org.tw/Open2.ashx?id={UUID}
```

從 URL 的 `id=` 參數抽出 UUID，存入 `pdfUUID` 欄位。

```python
from urllib.parse import urlparse, parse_qs
parsed = urlparse(pdf_url)
pdf_uuid = parse_qs(parsed.query).get("id", [""])[0]
```

若 URL 為空或無法抽取 UUID，`pdfUUID` 設為空字串，該商品標記為 `no_pdf`。

## 檔案命名規則

`[大類標籤] {公司短名} {商品名稱}_{民國啟售日}~{民國截止日}`

大類標籤對照：
| 保險類別 | 標籤 |
|---------|------|
| 健康保險 | [健] |
| 傷害保險 | [傷] |
| 人壽保險 | [壽] |
| 年金保險 | [年] |

---

## 過濾後的驗收標準

每次爬完後，確認輸出 JSON 中：
- 無「團體」「團險」等關鍵字的商品
- 無「延續條款」「停售後續」的商品
- 每個有 PDF 的商品都有 `pdfUUID` 欄位（非空字串）
