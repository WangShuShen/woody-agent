## 【Step 0】確認投保條件（三階段自動推算）

使用者提供保單後，依以下順序推算保額，**盡量不停下來問**：

### 階段一：識別保額來源類型（必須先判斷）

掃描文件，判斷屬於以下哪一種：

**【A型】附表型** — 文件含「每壹單位各項保險金給付金額」表格
- 特徵：有表格列出每單位金額
- 處理：使用者說「N單位」→ N × 表格各欄金額
- 範例：南山99終身防癌（附表：每壹單位各項保險金給付金額）

**【B型】直接保額型** — 保單首頁或封面直接列出各項「保險金額」
- 特徵：已印出具體數字，如「住院醫療保險金額：5,000元」
- 處理：直接使用各項金額，無需換算
- 範例：保單首頁已列出每個給付項目的金額

**【C型】保額回推型** — 條款文字定義倍數關係，從一個基礎保額推算所有項目
- 特徵：條款出現「住院日額之N倍」「保險金額之N%」「以X為計算基礎」等文字
- 處理：找出基礎保額（通常是住院日額或主保額），套用條款定義的倍數關係
- 範例：「加護病房保險金給付住院日額保險金額之2倍」→ 若日額1,000，加護病房=2,000

→ 識別類型後，傳給對應 Specialist Skill，並標明類型，例如：
  - `📋 保額來源：A型（附表），5單位`
  - `📋 保額來源：B型（直接保額），住院日額5,000元`
  - `📋 保額來源：C型（回推），基礎日額1,000元，倍數關係見條款`

### 階段二：N 單位 / 計畫別 自動換算
若使用者說「N 單位」或「計畫 X」且文件未含金額明細：
- 先詢問使用者：「請確認是否有商品說明書或要保書上的『每單位給付金額表』，不同產品單位金額差異可能高達 4~6 倍」
- 若使用者提供附表 → 依附表計算
- 若使用者說「直接用假設」→ 辨識險種後套用對應 Specialist Skill 中的 **📐 單位換算標準**，並標記誤差風險
- 在最終輸出「投保條件」行標記：
  `📐 已套用行業標準假設（誤差可能高達數倍），建議提供附表確認`

## 【Step 3】查理·蒙格最終校正

收到所有 Specialist 輸出後，切換視角，以查理·蒙格的方式執行最終校正。

> 「Invert, always invert. 要找到正確答案，先把所有可能出錯的地方找出來。」— Charlie Munger

**逐一執行校正清單：**

- [ ] **金額欄純淨**：只有數字 + 元，無括號、無計算式、無百分比
- [ ] **限制條件簡潔**：只有天數/次數/上限，不含說明文字
- [ ] **注意事項完整**：所有分層規則、倍數換算、例外條件都在此
- [ ] **無遺漏項目**：對照條款目錄，確認每個給付章節都有對應輸出
- [ ] **倍數已換算**：加護病房、燒燙傷已填入合計後數字（非原始日額）
- [ ] **金額計算正確**：骨折/脫臼已找最大部位換算，手術已按附表換算

校正完成後輸出蒙格校正紀錄（修正了什麼，或「無問題」）。
