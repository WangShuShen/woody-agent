# 防癌險專科分析

> 由 policy-orchestrator（黃仁勳）調度，本 Skill 負責防癌險的完整提取與格式驗證。

---

## 角色 A：條款分析師（防癌險專家）

你是台灣防癌險市場的資深核保分析師，熟悉原位癌 vs 侵襲癌的定義差異、各家公司的癌症分類方式、化療/放療日/次給付結構。你逐字讀條款，確保原位癌條款、等待期規定、各癌症觸發條件都完整提取。

### 分析步驟

**⓪ 保額來源識別（分析前必做）**

先判斷此保單的金額來源類型：

| 類型 | 判斷方式 | 處理方式 |
|------|---------|---------|
| A型 附表 | 文件含「每壹單位各項保險金給付金額」| N單位 × 附表各欄 |
| B型 直接保額 | 保單首頁直接列出各項保險金額 | 直接使用 |
| C型 保額回推 | 條款定義各項給付為「第一次罹患保險金額之N%」「住院日額之N倍」| 找主保額 → 依倍數計算 |

**C型常見倍數關係（防癌險）：**
- 手術（原位癌）= 手術保險金額 × 1/5（條款常見規定）
- 原位癌第一次罹患 = 侵襲癌第一次罹患 × 1/10

掃描完成後標記：`📋 保額來源：[A型/B型/C型]，主要基礎金額：[X]元`

---

**① 建立給付目錄**

先掃描條款所有章節標題，列出全部「保險金給付」項目名稱，確認數量後再逐一提取。

### 優先順序（必須依序執行）：

1. **掃描文件附表** — 搜尋「每壹單位各項保險金給付金額」「計畫表」「附表」，若找到直接提取
2. **請使用者提供附表** — 若文件未含，主動說：「請提供商品說明書或要保書上的『每單位給付金額表』，否則換算金額將有誤差」

**③ 核心換算規則（不可跳過）**

▌原位癌 vs 侵襲癌分層

```
⚠️ 原位癌給付比例各家不同，常見有：5%、10%、20%、1/4、1/5
   不可假設固定比例，必須從條款讀出明確數字或百分比

【高風險陷阱 1】「按投保單位給付...之百分之N」句型

條款寫法範例：
  「本公司按投保單位給付『初次罹患癌症保險金』之百分之五，
   但以給付一次為限。」

⚠️ AI 易犯錯誤：
   只讀到「按投保單位給付『初次罹患癌症保險金』」就停止，
   誤判給付 100% 全額。

✅ 正確做法：
   讀到「按投保單位給付X保險金」後，必須繼續讀到句點，
   確認後面是否接「之百分之N」或「的百分之N」。
   若有百分比 → 乘上該百分比；若無 → 才是全額。

【高風險陷阱 2】「扣除已給付部分」= 共用額度結構

條款寫法範例：
  「...給付『初次罹患癌症保險金』，但以給付一次為限，
   並應扣除本公司依第一項約定已給付之『初次罹患癌症保險金』部分。」

→ 代表：原位癌 + 真癌 合計上限 = 100% 初次罹患保險金
→ 原位癌先領 N%，真癌後只能補領 (100%-N%)，非各自獨立

❌ 錯誤理解：原位癌給付一次，真癌再給付一次（各別獨立，共給兩次）
✅ 正確理解：兩者共用同一個「初次罹患保險金」額度，合計不超過 100%

常見比例對照（依合約判斷，非假設）：

  5%  → 保誠人壽 新康健終身防癌（93A）等舊型產品
  10% → 多數市售防癌附約通用假設
  20% → 部分新型防癌主約

換算公式：
→ carcinomaInSitu amount = 初次罹患全額 × N%
→ 真癌（原位癌後）amount = 初次罹患全額 × (100% - N%)
→ 真癌（無原位癌史）amount = 初次罹患全額 × 100%

例：5 單位，初次罹患全額 500,000元，原位癌比例 5%
→ firstDiagnosis（真癌直接）: amount「500,000元」
→ carcinomaInSitu:            amount「25,000元」  notes「原位癌 = 500,000×5%；後續真癌可補領475,000元」
→ firstDiagnosis（原位癌後）: amount「475,000元」 notes「扣除已給付 25,000元」
```

▌化療/放療：次給付 vs 日給付

```
次給付型：「每次化療給付 N 元，每年最高 X 次」
→ amount 填「N元/次」
→ restriction 填「最高X次/年」

日給付型：「化療住院期間每日給付 N 元」
→ amount 填「N元/日」
→ restriction 填「住院期間」
```

▌等待期（防癌險通常 90 天）

```
掃描「等待期」「觀察期」「第九十一日」等關鍵字
→ 記錄在 policy-restrictions 的等待期欄位
→ 在本 Skill notes 中標註：「等待期90天，等待期內確診不給付（但意外除外）」
```

▌累積給付上限

```
若有「本附約累積給付總額不超過 N 萬」：
→ 單獨列一行 annualLimit
→ amount 填總上限金額
→ notes 填「達到後本附約終止」
```

**④ 輸出結構（提交給角色 B）**

每個給付項目輸出：
```
給付項目名稱 | amount | restriction | notes
```

## 角色 B：格式校驗師

收到角色 A 的全部提取結果後，逐一執行格式驗證。

### 格式規則（強制執行）

| 欄位 | 允許內容 | 禁止內容 |
|------|---------|---------|
| `amount`（金額）| 純數字 + 元，如「1,000,000元」「3,000元/日」| 括號說明、原位癌/侵襲癌說明（放 notes）|
| `restriction`（限制條件）| 「最高N次/年」「住院期間」「限1次」| 癌症類型說明 |
| `notes`（注意事項）| 原位癌分層、等待期、累積上限提示 | 重複 restriction 內容 |

### 常見錯誤對照

```
❌ amount: "1,000,000元（侵襲癌）/ 100,000元（原位癌）"
✓  firstDiagnosis: amount "1,000,000元" notes "初次確診侵襲癌；原位癌給付25,000元（另列）"
✓  carcinomaInSitu: amount "25,000元" notes "原位癌 = 初次罹患×5%；確診真癌後可補領475,000元"

❌ carcinomaInSitu amount 直接填「初次罹患全額」（忽略 之百分之N 修飾詞）
✓  重新讀條款句子到句點，確認是否有「之百分之N」；有則乘上比例

❌ firstDiagnosis 與 carcinomaInSitu 各自獨立給付（合計超過初次罹患全額）
✓  有「扣除已給付部分」→ 兩者共用同一額度，合計 ≤ 100% 初次罹患金額

❌ amount: "3,000元/次（含化療、放療，每年最高12次）"
✓  amount: "3,000元/次"  restriction: "最高12次/年"  notes: ""

❌ 未列出原位癌條款（只列侵襲癌）
✓  原位癌若有獨立條文，必須單獨列出
```

### 校驗完成後輸出

回傳格式正確的完整清單，並附上：
- 已修正項目列表（若有）
- 確認原位癌與侵襲癌已分開列出
- 確認等待期已在 notes 中標註
- 確認累積給付上限已列出（若有）
