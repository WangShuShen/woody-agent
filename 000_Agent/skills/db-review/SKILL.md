# db-review — 審核 Sheet 規範

---

## 工作表結構

每份保單建立一個 Google Spreadsheet，包含三個工作表：

| 工作表 | 內容 |
|--------|------|
| `給付項目審核` | 每個給付項目一行，含公式/金額與審核狀態 |
| `除外責任與限制` | 等待期、除外清單、特別限制 |
| `理賠必要文件` | 各申請情境所需文件 |

---

## 工作表 1：給付項目審核

### 列結構（Row layout）

| Row | 內容 |
|-----|------|
| 1 | 標題 1：`【險種】公司 ｜ 商品 ｜ planCode`（全欄合併） |
| 2 | 標題 2：`保額基礎：… ｜ 險種：… ｜ 提取日期：…`（全欄合併） |
| 3 | **每單位保額試算**：A:B 合併（標籤），C = 使用者輸入數字（黃色高亮） |
| 4 | 欄位標題（凍結） |
| 5+ | 資料行（每給付項目一行） |
| 末行 | 「⚠️ 累積給付上限」 |

### 欄位定義（A 到 F 欄）

| 欄 | 欄位名稱 | 類型 | 說明 |
|---|---------|------|------|
| A | 審核狀態 | Dropdown | 待審核 / 確認正確 / 需修改 / 忽略此項 / 進一步核實 |
| B | 給付項目名稱 | 文字 | — |
| C | 給付金額（公式文字）| 文字 | 如「日額×1/日」「單位×3/次」 |
| D | 計算金額 | 公式 | `=IF($C$3>0,TEXT(ROUND($C$3*{倍率},0),"#,##0"),"—")`；C3 為每單位保額輸入格 |
| E | 限制條件 | 文字 | 如「最高30日/年」 |
| F | 注意事項 | 文字 | 如「等待期90天」 |

> Row 3 的 C3 格為可編輯輸入格（亮黃底），使用者輸入每單位保額後，D 欄自動計算所有項目金額。

### 審核狀態下拉選項

```python
REVIEW_STATUS_OPTIONS = ["待審核", "確認正確", "需修改", "忽略此項", "進一步核實"]
```

## 工作表 2：除外責任與限制

### 欄位定義（A 到 B 欄）

| 欄 | 欄位名稱 | 類型 | 下拉選項 |
|---|---------|------|---------|
| A | 類別 | Dropdown | 等待期 / 除外責任 / 特別限制 / 給付觸發條件 |
| B | 內容 | 文字 | — |

> Row 1：標題（合併全欄）
> Row 2：整體審核狀態（A = 標籤，B = 下拉）
> Row 4+：資料行

## 工作表 3：理賠必要文件

### 欄位定義（A 到 B 欄）

| 欄 | 欄位名稱 | 類型 | 下拉選項 |
|---|---------|------|---------|
| A | 申請情境 | Dropdown | 每次申請必備 / 住院申請 / 手術申請 / 出院後申請 / 重大疾病確診 / 身故申請 / 其他 |
| B | 必要文件 | 文字 | — |

---

## Sheet 標題命名規則

```
【待審核】{company} {productName} {YYYYMMDD}
```

例：`【待審核】南山人壽保險股份有限公司 南山人壽醫療給付終身保險 20260602`

---

## 審核完成確認（可歸檔條件）

- `給付項目審核` 工作表的 A 欄，無任何「待審核」「需修改」「進一步核實」
- A 欄只剩「確認正確」或「忽略此項」

---

## 實作位置

`push_to_sheets.py` 的 `build_coverage_sheet()` 使用 Google Sheets API `batchUpdate` 實作所有格式，**不使用** `gspread-formatting` 套件。
