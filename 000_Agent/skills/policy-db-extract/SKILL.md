# policy-db-extract — 保單資料庫提取模式

> 與 policy-orchestrator 的差別只有一個：
> **不帶入實際金額，只提取倍數公式與結構，供資料庫儲存。**

---

## 【Step 0】識別保額基礎類型

掃描文件，判斷此保單的金額基礎屬於哪一種，決定公式的「變數名稱」：

| 類型 | 判斷方式 | 資料庫變數名稱 |
|------|---------|-------------|
| **C型 日額回推** | 條款全程用「單位日額」「住院日額之N倍」 | `日額` |
| **A型 附表單位** | 文件含「每壹單位各項保險金給付金額」表格 | `單位` |
| **B型 計劃別** | 封面或目錄列出計劃A/B/C或計劃1/2/3，各計劃金額不同 | `計劃別` |
| **B型 直接保額** | 保單首頁直接印出各項保險金額（固定數字） | `固定` |

宣告：`📋 保額基礎類型：[類型]，資料庫變數：[變數名稱]`

---

## 【Step 1】險種辨識

快速掃描封面、目錄、條款名稱，辨識險種（可複數）：

| 關鍵字 | 險種 |
|--------|------|
| 住院日額、加護病房、手術給付（定額型）| 定額醫療 |
| 收據、實支實付、雜費、住院費用上限 | 醫療實支 |
| 意外、傷害、骨折、脫臼、失能（意外型）| 意外傷害 |
| 癌症、惡性腫瘤、初次罹癌 | 防癌險 |
| 重大傷病卡、健保重大傷病認定 | 重大傷病卡 |
| 7項重大疾病、22項特定傷病 | 特定傷病 |
| 失能、1~11級、失能扶助月給付 | 失能險 |
| 長期照顧、巴氏量表、ADL六項 | 長照險 |
| 壽險、身故保險金、生存金、滿期金 | 壽險 |

---

## 【Step 2】提取給付項目公式

依保額基礎類型，用對應方式提取每個給付項目：

### C型 / A型（日額或單位制）

每個給付項目輸出：`公式 = 變數 × 倍數`

**常見倍數關係對照：**

| 給付項目 | 條款寫法 | 公式寫法 |
|---------|---------|---------|
| 住院日額 | 「按住院日數乘以單位日額」| `日額×1/日` |
| 加護病房（另給付合計） | 「另給付單位日額之2倍」→ 合計 = 日額 + 2×日額 | `日額×3/日` |
| 重大手術 | 「投保之單位日額之五十倍」| `日額×50/次` |
| 住院前後門診 | 「單位日額百分之二十五乘以門診次數」| `日額×0.25/次` |
| 出院療養 | 「單位日額百分之五十乘以住院日數」| `日額×0.5/日` |
| 緊急醫療運送 | 「投保之單位日額之二倍」| `日額×2/次` |
| 身故保險金 | 「投保之單位日額之一千倍」| `日額×1000` |
| 累積給付上限 | 「單位日額之一千倍為限」| `日額×1000` |

### B型 計劃別

針對每個計劃（A/B/C 或 計劃1/2/3），分別列出各項目的**固定金額**：

```
計劃別        給付項目          金額           限制條件
計劃A         住院日額          X,XXX元/日     ...
計劃B         住院日額          X,XXX元/日     ...
計劃C         住院日額          X,XXX元/日     ...
```

### B型 直接保額

直接填入保單首頁印出的固定金額，不需要任何換算。

---

## 【Step 3】理賠限制提取

提取以下項目（格式同 policy-restrictions）：

- 等待期（疾病 / 傷害 / 增加保額）
- 除外責任（四類：人為行為 / 特定行為 / 特定情況 / 法規）
- 特別限制（累積上限 / 同一住院限制 / 觸發條件）

---

## 【Step 4】理賠文件提取

依本保單涵蓋的給付項目，列出各申請情境所需文件（格式同 policy-claim-docs）。

---

## 【Step 5】蒙格校正

執行格式校驗：

- [ ] 公式欄只有「變數×倍數」，無實際金額、無括號、無說明文字
- [ ] 限制條件欄只有天數/次數，無說明文字
- [ ] 加護病房/燒燙傷已計算合計倍數（非原始條款倍數）
- [ ] 計劃別保單已列出所有計劃，無遺漏
- [ ] JSON 輸出欄位完整，無 null、無空字串

---

## 護欄

- **不輸入保額也能跑**：整個流程不需要使用者提供保額、年齡、性別
- **公式欄不含實際數字**：`日額×3` 而不是 `3,000元`（除非是 B型固定保額）
- **計劃別保單**：有幾個計劃就輸出幾組，不省略
- **蒙格校正必做**：輸出前一定要跑 Step 5，不可跳過
